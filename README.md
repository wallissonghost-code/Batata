# ROUND NOT

Protótipo de jogo automático para lives interativas.

## V1
- Canvas 2D responsivo
- 36 bots de teste com `@user`
- caminhada automática com velocidades diferentes
- fases aleatórias **PODE ANDAR / NÃO SE MEXA**
- atraso/falha de reação individual e eliminação
- cronômetro de 3 minutos
- linha de chegada, sobreviventes e resultado final
- HUD de vivos, classificados e eliminados
- botão para adicionar bots durante a partida

A integração com TikTok/Projeto Daniel fica isolada para uma próxima etapa, depois de validar gameplay e desempenho.
